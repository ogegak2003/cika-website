# CiKA Company Website

A modern, responsive company website for CiKA Technologies built with React, Tailwind CSS, and Node.js.

## Features

- 🏠 Modern Homepage with Hero Section
- 🛠️ Services Page with Detailed Offerings
- 👥 About Page with Company Story & Team
- 📞 Contact Page with Form Validation
- 💬 Real-time Live Chat Support
- 📱 Fully Responsive Design
- 🎨 Smooth Animations with Framer Motion
- 🐳 Docker Containerization
- 🔄 CI/CD Ready

## Tech Stack

### Frontend
- React 18
- Vite
- Tailwind CSS
- Framer Motion
- React Hook Form
- React Router DOM
- Socket.io Client

### Backend
- Node.js
- Express.js
- Socket.io
- MongoDB
- Mongoose
